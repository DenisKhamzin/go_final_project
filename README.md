#Проект таск-трекера (финальное задание)

В проекте реализован API возможностью получения списка текущих задач, а добавления, изменения, завершения и удаления задач. Все текущие задачи хранятся в БД scheduler.db (СУБД Sqlite).
Задачи повышенной сложности (со звездочкой) не реализовывались.

##Запуск

Для запуска необходимо запустить main.go. Сервер "слушает" порт 7540

##Тестирование

Тесты для проверки функционала API содержатся в директории /tests. Для запуска тестов необходимо запустить сервер, а затем выполнить команду go test ./tests
